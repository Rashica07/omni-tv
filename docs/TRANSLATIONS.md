# Translations

OMNI's own screens are available in **English, Albanian (Shqip), Italian and Swiss Standard German** (written the Swiss way, without the sharp s). The language is chosen at first run and under Settings > Language; until then it follows the TV's language when that is one of these.

* The English text is the key (`Tr.java`); a missing translation shows English. A test requires every entry to have all three translations and the same placeholders.
* Covered: navigation, Home, Live TV, Settings, the setup, quick access, remote button targets. **Not yet covered:** messages that are built from many parts at run time, the Server, Cinema, Weather and Gallery apps, the assistant, system dialogs.
* Swiss German here means *Swiss Standard German* (de-CH spelling and a few Swiss word choices). Spoken Swiss German dialects have no standard spelling, so they are not written out.
* **These translations were written by an AI assistant and have not been reviewed by native speakers.** Corrections are very welcome: edit the matching line in `android/app/src/main/java/com/rasha/omni/Tr.java` and open a pull request, or open an issue.
